Lesson 1 — What is logic?

Logic is just decision-making written down. You already use it every single day — you just never called it that. Read through these three everyday examples and you will immediately recognise the pattern.

🚦
Traffic lights
IF light is green
→ THEN drive
IF light is red
→ THEN stop

The condition (light colour) decides which action to take. This is exactly how automation filters work.

🍳
A recipe
WHEN eggs are ready
→ ADD salt
IF runny → cook 1 more min
IF firm → serve now

A recipe is a sequence of steps with conditions. Automations work exactly the same way — step by step, checking conditions.

📬
Your email inbox
WHEN email arrives
IF from = "boss"
→ THEN mark urgent
ELSE → move to folder

Gmail's filter rules are literally an automation. You may have set some up already without realising it.

💡
Notice the pattern? Every example follows the same structure: something happens → check a condition → do something. That is the entire logic of automation. Everything in Zapier and n8n is just this pattern repeated.

Lesson 2 — IF / THEN / ELSE

These three words are the grammar of logic. Once you understand them, you can read any automation like a sentence.

IF — the condition

The question you are asking. Is something true or false? It always has a yes/no answer.

IF email subject
contains "Invoice"
THEN — the yes path

What happens when the condition is true. The automation continues down this path.

THEN add row
to Google Sheets
ELSE — the no path

What happens when the condition is false. Optional — many automations just stop if the condition is not met.

ELSE do nothing
(skip this email)
Read this like a sentence:
WHEN a new email arrives in Gmail
  IF the subject contains "Invoice"
    THEN add a row to Google Sheets
  ELSE
    ignore it

This is a real, working Zapier automation written in plain English. When you build it in the tool, it looks exactly like this — just with buttons and dropdowns instead of text.

Lesson 3 — Order matters

Automations run step by step, top to bottom. The order of steps is critical. Think of it like giving directions — if you say "turn right" before "go straight", you end up somewhere wrong.

Example — Morning routine as an automation:
1
TRIGGER — Alarm goes off at 7am
The event that starts everything. Without this, nothing runs.
2
CONDITION — IF it is a weekday
Check the condition. If false (weekend), skip to ELSE — sleep in.
3
ACTION 1 — Make coffee
First action. Must come before getting dressed — you need the coffee first.
4
ACTION 2 — Get dressed and leave
Second action. Depends on step 3 being done first. Order is critical.

Now — the 4 concepts behind every automation

⚡

Trigger

The event that starts the automation. Something that happens.

A new email arrives in Gmail
🎯

Action

What the automation does after the trigger fires.

→ Add a row to Google Sheets
🔍

Condition (Filter)

A rule that decides whether to continue. Only proceed if something is true.

Only IF subject contains "Invoice"
📦

Variable (Data)

A piece of information passed from one step to the next.

Use {{sender_name}} in the reply
💡
Every automation you will ever build — in Zapier, n8n, or any other tool — is just a combination of these four things. Learn them now and the tools will make sense immediately.
